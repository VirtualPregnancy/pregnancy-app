What I should do if I want to modify the landing page?
====================================================

.. include:: ../style.rst

Modify the landingPageData.json file under ./frontend/assets/data/landingPageData.json, and change the content of the landing page.

You can change the index of the item to change the order of the items.

Refer to this document for more details: :ref:`implementation_structure/02_assets:Landing Page Configuration`
