Which data files are used to manage content and where are they located?
======================================================================

.. include:: ../style.rst

The location of the data files is the 'assets/data' folder. These include:

- :blue:`topics.json`, which contains all information related to the topics along with their subtopics.
- :blue:`modelData.json`, contains the configuration for the models and their associated data.
- :blue:`landingPageData.json`, contains the configuration for the landing page.
- :blue:`supportData.json`, contains the configuration for the support services page.
