Deploy documentation on readthedocs
=====================================
Test the documentation locally
--------------------------------
You can test the documentation locally by running the following command:

.. code-block:: bash
    :linenos:

    cd docs
    ./dev.sh


Then you can view the documentation in the ``build/html`` folder.
And then you can view the documentation in the browse.

Deploy the documentation on readthedocs
--------------------------------------

1. Create your readthedocs account(recommend using your GitHub account).
2. Import the repo that you want to deploy
3. Choose a branch
4. Click ``Build``
