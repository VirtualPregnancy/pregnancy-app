Project Overview
===============

Virtual Pregnancy is a pregnancy health education web-app for pregnant women and their families in New Zealand.

Tech Stack
----------
* Nuxt.js 2
* Vue 2
* Vuetify
* Three.js
* Copper3D

Target Users
------------
Pregnant women and their families in New Zealand

Core Features
-------------
* Interactive 3D placental models
* Healthy pregnancy information
* Pregnancy complications guidance
