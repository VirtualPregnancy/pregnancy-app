Color
=======

Background Color
----------------
The color of background is defined in the `nuxt.config.js` file. The color palette is according to `Manu`_ (https://g-thomson.github.io/Manu/#takah%C4%93---porphyrio-hochstetteri)

.. _Manu: https://g-thomson.github.io/Manu/#takah%C4%93---porphyrio-hochstetteri

Menu Button Color
-----------------
The color of menu button is defined in the :red:`nuxt.config.js` file. Defined as following:

.. code-block:: javascript

  // for menu buttons
  buttonMain: "#3E7C93",           
  buttonMainActive: "#2b6378",   
  buttonSubmenu: "#6C90B9",        
  buttonSubmenuActive: "#4d6c8f",
    

.. _Manu: https://g-thomson.github.io/Manu/#takah%C4%93---porphyrio-hochstetteri
